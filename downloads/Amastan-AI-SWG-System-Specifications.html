1. Product summary

Amastan is a self-hosted AI Secure Web Gateway. It inspects outbound web traffic, applies allow / block / optional Remote Browser Isolation (RBI) decisions, and keeps verdicts and logs on infrastructure you control.

Verdicts: Allow · Block · Isolate (RBI)

3. Deployment model

  • Appliance-oriented Docker Compose / HA stack
  • Lab and pilot images distributed as KVM/QEMU qcow2 (sanitized pilot build)
  • Single-site today; multi-site fleet on roadmap

6. Identity & integrations

  • LDAP / Active Directory federation
  • Directory users & endpoint agent path (Windows)
  • SIEM-oriented export (syslog / object storage / webhooks as configured)
  • Azure AD / SAML / OIDC hardening on roadmap

7. Security properties

  • On-prem verdicts and audit trail
  • Policy allowlist / blocklist / overrides / SNI bypass controls
  • Tamper-evident audit chain (as implemented in pilot)
  • Optional licensed modules: DLP, email security, shadow IT discovery
